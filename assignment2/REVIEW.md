## 特征的具体语义

NB 仍然是像素朴素贝叶斯。预处理依次为矩去倾斜、24×24 包围框拉伸、28×28 画布质心对齐、八档灰度。每个像素的零灰度背景状态也进入对数似然。

BN 的 F1 至 F9 分别是九个 8×8 区域的**无向梯度主轴角**，不是九个区域密度。固定四档梯度直方图经二倍角圆周均值压缩为一个角度，再离散为五档；无梯度区域约定角度零。这些直方图值是确定性计算中间量，不是额外随机图节点。

F10 是去倾斜后 `>64` 前景包围框宽高比；F11、F12 是原阈值图背景四连通定义的孔洞，在同一框内映射到 21×21 后，上 10 行/下 11 行的面积比例。方向采样为 24×24，孔洞采样为 21×21，分母分别是 210 和 231，勿混淆。

所有特征都由输入图像的固定几何运算得到，不需要标签、已训练的其他模型或批次统计量。实际图中只有 Y 和十二个已观测特征。

## 实验与版本核查

1. 原始训练集按种子 `20261019` 固定划成 50,000 / 10,000，验证集每类 1,000 张。`results/optimization/validation_indices.csv` 保存索引。
2. `selection.json` 保留 48 个 NB 配置和 160 个 BN 配置。排名只用验证 Macro F1，再用 Accuracy。
3. 正式代码在验证集复现 NB 91.04%、BN 92.09%，之后写入 `selected_config.json` 冻结，最终再用完整训练集拟合和测试。
4. 最终记录的源码 SHA-256 应与当前根目录文件一致，冻结时间应早于本版 `run_metadata.json` 时间。
5. 同特征的无依赖边消融验证准确率为 90.49%，固定手工 DAG 为 92.09%。无边模型仅作消融，没有作为提交 BN，也没有用于结构学习。
6. `history/previous/` 和 `history/initial/` 各自保留完整资产。校验前版文件时使用对应目录内的交付清单。
7. 公开测试集在前两版中已被查看，因此最终比较不能称为完全未接触的独立测试。本轮候选排序不读取测试文件。

## 可执行检查

```console
python -m pip install -r requirements.txt
python verify_results.py
python main.py --data-dir ../assignment2-data/mnist --output-dir independent-run
python optimize_target90.py --data-dir ../assignment2-data/mnist --output-dir selection-recheck
```

`verify_results.py` 无需原始数据，会核对两个历史版本、冻结模型和实验源码，从 CSV 独立重算指标及矩阵，并执行 23 项检查。其检查包括手算 CPT/像素似然、几何质心、已知方向斜坡、闭环/开环、接口和概率归一化。

重跑最终模型应比较预测、指标和混淆矩阵；耗时与时间戳会变化。重跑候选应比较验证索引和选中方案。检查脚本会改写测试日志及审计记录，其交付哈希会随重跑变化。不要仅凭本说明或检查通过而跳过源码与公式复核。

## 仍存在的局限

NB 的拉伸可能放大窄字形的横向差异；BN 的主方向在近各向同性区域可能不稳定，角度分界与孔洞也对小变形敏感。208 个配置共享同一个验证划分，存在选择带来的乐观性。报告包含剩余易混淆数字对和原始错误样例，没有宣称所有类别都已同等改善。
