# Gemini / 人工复核入口

本文件说明可以如何独立核查本次基线。它记录已实施的设计和检查路径，不替代复核者的判断。

## 作业约束映射

| 要求 | 本实现及检查位置 |

| 全量训练/测试数据 | 课程读取器强制训练 60,000、测试 10,000；四个压缩文件校验值检查 |

| 报告使用 Markdown | `report.md`；PDF 为课程可选项，本基线不额外生成 |

## 建议的独立复核顺序

1. 对照原始作业 PDF，检查上述映射是否遗漏约束。
2. 单独读取两个模型文件，核对公式和 CPT 索引，避免仅根据测试是否通过判断。
3. 执行 `python -m unittest discover -s tests -v`。17 项检查包含与手工公式的数值比较、未见类别/父配置的平滑、概率归一化、DAG 父节点约束、批次独立性与接口加载。
4. 用 `python main.py --data-dir ../assignment2-data/mnist --output-dir independent-run` 独立重跑。比较预测标签、四项指标与混淆矩阵；耗时和时间戳会随环境变化。
5. 直接从 `results/predictions.csv` 重算混淆矩阵，检查结果行数恰为 10,000。Macro F1 为逐类别 F1 的算术平均，包含全部十类，零分母按 0 处理。
6. 对照 `results/run_metadata.json` 中的代码 SHA-256，确认检查的源文件与已记录实验一致。报告和此说明不是模型输入，也不应被当成检查通过的证据。
7. 打开全部 PNG，检查数字样例、标签、DAG 边和混淆矩阵方向；结合每类指标审阅报告的解释。

## 特别值得核查的细节

- Bernoulli Naive Bayes 对黑色背景同样建模；只累加前景概率会得到另一种模型。
- NB 用 `pixel > 128` 判定前景，等于 128 的像素属于背景。
- 区域密度是灰度均值除以 255，不是二值像素占比。3×3 网格的边界为 0、9、19、28，按每块实际面积取均值。
- 宽高比由 `pixel > 128` 的最小包围框计算；空图的比值定义为 0。左右和上下不对称度使用灰度图与其镜像之间的绝对差之和，除以两倍墨迹总量；空图定义为 0。
- 所有离散化阈值固定，等于阈值时进入更高的状态；不存在批次分位数或利用测试标签的步骤。
- DAG 中的额外特征父节点按代码从零编号，报告从 F1 编号。二者相差 1，不应混淆。
- CPT 的分母是指定父配置下的样本数加 `5*alpha`，不是该类别的总样本数。
- Y 的根分布也使用加性平滑。缺少某个训练类别时，两模型仍保留全部十个输出类别。
- 图像样例采用测试顺序中的前六个错误，并未声称代表全部错误分布。测试集用于最终评估与事后误差分析。
- 小型贝叶斯网络与 NB 的特征空间不同，精度差不能只归因于依赖边。报告区分了这一限制。
