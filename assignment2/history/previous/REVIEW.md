# Gemini / 人工复核入口：优化版

优化版最终准确率为 NB 87.75%、BN 85.16%。初版为 84.33%、55.91%。本文件列出独立复核的路径，不替代复核者判断。

## 版本和选型记录

- `history/initial/report.md` 与同目录中的图像、代码和结果为完整初版快照。原报告 SHA-256 为 `76e44351555726ef04c2f17b4ae8dda5d1b9982f22fae41560982fef56e8387a`；历史目录的原交付清单可逐文件核对。
- `optimization_protocol.json` 记录候选范围、固定种子、验证规则和不学习结构的限制。
- `optimize.py` 只读取原始训练图像及训练标签；固定划分 50,000 张训练、10,000 张验证，每类验证 1,000 张。
- `results/optimization/selection.json` 保留全部 54 组候选。指标首选验证 Macro F1，然后 Accuracy。
- `selected_config.json` 保留复现验证结果后、最终测试前冻结的配置和核心源码校验值。
- 原始测试集初版已被查看。本轮没有用测试集排序候选，但不能把最终比较描述为完全未接触过的独立测试。

## 作业限制映射

| 限制 | 当前实现 |
|---|---|
| 固定文件名、类名、接口签名 | `NaiveBayesClassifier`、`BayesNetClassifier`；构造默认仍为 `alpha=1.0`，fit 返回 self |
| 模型接收原始 `(n,784)` 图像 | 两文件自行完成全部预处理，不要求调用者提供离散特征 |
| NB 概率估计与预测自行实现 | NumPy 计数及对数类别分数；去倾斜后每像素八个灰度状态 |
| NB 平滑与对数运算 | 每个像素状态分别加 alpha，分母为类别样本数加 `8*alpha` |
| BN 6 至 12 个离散特征，每项 2 至 5 状态 | 9 个归一化区域密度、原包围框宽高比、上下孔洞比例，共 12 项，各 5 状态 |
| Y 根节点，无隐藏变量 | 共 13 个节点，Y 指向全部特征 |
| 至少两条特征间有向边 | 手工固定八条，与初版连接编号一致 |
| 每个特征最多两个父节点 | 包含 Y 在内最多两个；父特征编号总小于子特征 |
| 不使用自动结构学习 | 所有候选使用同一 DAG，没有搜索、评分或排名依赖边 |
| 所有 CPT 平滑 | 每个完整父配置分母为该配置次数加 `5*alpha`，未见父配置为均匀分布 |
| 对数联合概率预测 | Y 的对数先验，加全部 12 个已观测特征的对数条件概率 |
| 完整测试集与四项指标 | `metrics.json`、10,000 行 `predictions.csv`、两个混淆矩阵 CSV |
| DAG 与每条边解释 | `figures/bayes_network.*`、报告中的十二条类别边及八条特征边表格 |
| 至少三张错误样例与分析 | 两模型各六张，固定取原测试顺序中的前六个错误 |
| Markdown 报告与提交文件 | 根目录包含规定的五个提交文件；PDF 为课程可选项 |
| 不提交原始 MNIST | 数据和虚拟环境在交付目录外，`.gitignore` 屏蔽 gzip |

## 特别区分的事项

1. 类构造函数严格默认 `alpha=1.0`，训练入口显式使用验证选出的 `0.1`。报告对应后者。NB 的八档是像素灰度档，BN 的每项仍满足 2 至 5 状态限制。
2. NB 只做逐图矩去倾斜和灰度分箱。BN 做 `>64` 前景包围框采样到 21×21，没有调用 NB 去倾斜。
3. NB 每个像素都取一个状态似然，背景状态 0 同样计入，不只累计非零像素。
4. 孔洞在原始阈值图上以背景四连通定义，先计算连通性，再按同一包围框映射采样。上半 210 个像素、下半 231 个像素，各按自己的面积归一化。
5. BN 分箱固定、边界归入较高档，`extract_features(X)` 不依赖标签、批次统计量或已拟合对象。
6. 无特征边模型仅用于同特征消融，没有参与候选结构搜索，也不是最终提交模型。
7. 初版与优化版的完整测试结果都使用 60,000 张训练图像；验证实验使用固定 50,000 张训练子集。两种数据划分的数值应分别比较。

## 建议复核命令

```console
python -m pip install -r requirements.txt
python verify_results.py
python main.py --data-dir ../assignment2-data/mnist --output-dir independent-run
python optimize.py --data-dir ../assignment2-data/mnist --output-dir selection-recheck
```

`verify_results.py` 无需原始数据，会核对冻结模型、完整初版快照、CSV 独立复算及 21 项数值/接口检查。它会改写 `results/audit.json` 和测试日志；交付清单中这些文件的哈希会随重新执行而变化。

重跑 main 时请比较预测标签、混淆矩阵和四项指标；耗时、时间戳和命令路径随环境变化。重跑 optimize 时请比较验证索引、54 组配置、选中方案及其验证指标。不要仅凭本文件或检查通过就跳过源码和公式复核。

## 已知局限

当前 NB 的 4、9 混淆合计仍为 202 次，整体提升没有改善全部数字对。BN 对细小断笔敏感，孔洞会随阈值和背景连通规则变化。只使用一个验证划分评估 54 个候选也存在选择带来的乐观性。报告保留这些限制，并区分了数据事实、消融结果和事后视觉解释。
